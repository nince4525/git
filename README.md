# PAF(Programming and Algorithm Fundation)
---

## 本库存简介
本库存是《程序设计与算法基础》课程的资料库。《程序设计与算法基础》课程由三个模块构成：
- 《程序设计与算法基础I》：以C语言为载体，讲解程序设计方法，以及算法初步
- 《程序设计与算法基础II》：以C语言为载体，讲解经典常用数据结构和算法

>本学期只发布《程序设计与算法基础II》课程的资料
